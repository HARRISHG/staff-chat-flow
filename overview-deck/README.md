# Patientcurve overview deck

The general deck for any dental clinic: the problem, why it happens, the solution, how it works, features, an example journey, getting started, principles and FAQs.

Output: `../Patientcurve-Overview.pptx` (and `.pdf`).

Rebuild (needs `pptxgenjs`, `react`, `react-dom`, `react-icons`, `sharp`):

```bash
npm install pptxgenjs react react-dom react-icons sharp
node build-overview.js ../Patientcurve-Overview.pptx
```
